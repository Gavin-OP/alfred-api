如何运行与验证

仓库已含 .venv，依赖已装好；无需 API key 即可跑测试（走 FakeProvider）。下面是 PowerShell 命令： 

# 1) 跑全部测试（SQLite 内存库 + FakeProvider，无需外部依赖）
.venv\Scripts\python -m pytest -q

# 或用 uv（若已安装）
uv run pytest -q

# 2) 起交互式文档 / 开发服务器（默认 sqlite；接真实 LLM 需 .env 的 OPENAI_API_KEY）
cp .env.example .env          # 编辑 OPENAI_API_KEY
.venv\Scripts\python -m alfred.main
# 或：uv run uvicorn alfred.main:app --reload --port 8000
# 打开 http://localhost:8000/docs 查看 OpenAPI

# 3) 接 PostgreSQL（可选）
docker compose up -d db
uv run alembic upgrade head
uv run uvicorn alfred.main:app --reload --port 8000

验证点：测试全绿（57 passed）即代表 service / skill / API contract 三层都通过； /v1/llm-ping 验证 LLM 连通；/v1/skills/coffee_chat/dry-run 走 dry-run 不落库。
